# 成品验收与待定输入

目标用途已确定为地面试验、总线监测和数据分析。当前完成软件架构基线；设备和工况输入尚未确定，不能用模拟软件通过替代成品先进性验收。

| 必需输入 | 当前状态 | 决定的验收项目 |
| --- | --- | --- |
| 总线种类及协议版本 | 首选 MIL-STD-1553B；当前为合成监控输入的软件子集 | 原始记录单元、帧元数据、解析器和错误映射 |
| 采集卡型号、SDK/驱动版本 | 待定 | 进程边界、回调等待、设备交接、拔插和复位 |
| 通道数、正常/峰值速率与帧长分布 | 待定 | 总量/单来源/IPC 预算、存储带宽和过载方式 |
| 连续运行时长、磁盘保留策略 | 待定 | 文件分段、容量余量、磁盘满与长时状态预算 |
| ICD、工程量和有效性定义 | 待定 | 解码正确性和真实关联规则 |
| 时间同步来源、误差界和跨源偏差 | 待定 | 时钟映射、允许迟到范围、空闲水位和响应可信区间 |
| 界面、自动化控制和交付平台 | 已有 Qt 地面工作台和结构化控制接口；设备交互待确定 | 产品交互与系统集成验收 |

软件成功标准是：预算在采集前或明确的系统入口执行；窗口内重排不改变已定义的关联结论；分析故障仍保留原始数据；SDK 用户态故障不终止宿主或其他来源；未封存输入无法误报完整；错误、配置和版本可追溯；干净源码可构建并通过回归及公开命令行故障验收。

设备阶段的主要指标应按同一工况测量：入口帧数/有效载荷字节数除以观察时长；设备计数与宿主入口/拒绝/落盘计数的闭合；采集到记录完成延迟的分位数；分析积压和恢复耗时；连续运行内存与磁盘增长；标定后跨通道时差及漂移。尚未定义计数来源或时间基准的指标记为 unknown，不用零代替缺失观测。

真实 SDK 应补充断连、驱动重置、回调停不下、设备占用、过载和磁盘满测试。每次升级保留 SDK、驱动、插件二进制、软件提交、配置与原始记录身份。单次采集只有来源健康、入口计数可核对、记录封存通过、分析状态符合用途时才可进入成功验收；任一来源错误使本次采集降级。

本轮相对基线的改进可用故障边界、确定性、容量预检和配置扩展成本证明。行业先进性还需在选定硬件、同一通道/速率/时长和同样的误差定义下与目标产品比较；公开功能列表不能代替此项性能和可靠性对照。
