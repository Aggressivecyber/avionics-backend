# 地面监测后端软件升级验收计划

本阶段以地面试验和总线监测为范围。开发分支为 `codex/ground-backend-v03`，基线为 `0f00e927424f73fe5deb07b7da41aab13527ecf1`；开发、构建和运行文件放在 E 盘，原工作区保留基线。

用户在 2026-10-19 明确调整范围：项目尚未上线，不要求兼容旧版；旧插件统一重做。因此当前只接受插件 ABI 2、归档格式 2、配置 schema 2，移除旧版适配与迁移验收。基线仅用于比较和回退开发改动。

当前审计及复现位于 [架构审计](E:/avionics-audits/20261019-architecture-094835/architecture-audit.md)。

| 工作项 | 验收条件 | 状态 |
| --- | --- | --- |
| 配置与状态容量 | 声明的参数状态在采集前完成预算检查，超限配置不能在采集中途首次报错 | 已通过 4097 参数的拒绝与扩容运行验收 |
| 字段与规则索引 | 无关字段和规则不逐项扫描，既有输出语义保持一致，记录扩展微基准 | 字段、时钟、输入规则和活动截止索引已完成并通过回归 |
| 核心接口依赖 | 参数接口独立于归档、队列及线程实现 | 已完成并通过构建 |
| 事件时间 | 明确配置允许迟到范围，有界重排；范围内跨来源排列结论一致，截止和空闲边界有测试 | 已通过 60 种来源交错、截止水位及异常时间验收；空闲等待不自动生成设备水位 |
| 记录与分析隔离 | 分析故障或积压不终止原始记录，持久化缺口和分析游标明确，原始存储失败仍显式失败 | 已通过异常、队列及收尾故障注入和完整离线重算 |
| 输入预算 | 总量和来源分别有条数、字节预算及拒绝原因 | 已通过条数、字节及来源状态容量验收 |
| 会话封存 | 新格式可验证记录数量、长度和内容；能区分未封存输入 | 已通过 69 类破损及并发独占写入验收；旧版读取按用户指示移除 |
| 异步故障 | 工作线程错误可通过公开状态取得原因并保存在会话结果 | 已通过异常原因、退出码、移除后持久化及公开 CLI 退出码 4 验收 |
| 升级维护 | 配置和发布版本可追溯，失败替换可回滚；旧插件按新接口重做 | 失败替换与回滚已通过；发布版提供提交身份、源码和摘要清单 |
| 证据身份 | 配置解析字节与保存快照一致，配置内容和会话有稳定身份 | 已通过在线离线相同身份、Python 独立摘要复核和回放原始会话身份验收 |
| 用户态故障隔离 | 通用采集进程崩溃或挂起时宿主及其他来源保持可用，停止与恢复结果可查询 | 已通过线程异常、退出、加载/配置/启动/停止挂起、最大帧及手动恢复；父退出不留采集进程 |
| Qt 配套前端 | 独立界面进程，采集控制不阻塞界面，在线显示和离线复算使用真实后端数据 | 已接入 Qt Widgets / PySide6；四组桌面集成测试及截图说明见 [Qt 前端](qt-frontend.md) |
| 交付验证 | 干净构建、全部回归、故障注入、运行包及可核验收据 | 最终结果以交付目录的 `verification/receipt.json` 为准；不含已取消的旧版兼容测试 |

实施顺序为容量与索引、事件时间、记录隔离、封存与追溯、新版插件及采集进程边界，最后汇总交付验证。各阶段保留覆盖审计问题的回归及故障验收。

真实总线识别算法、采集卡 SDK、设备参数 ICD 和绝对吞吐、延迟及连续运行目标，在规格确定后验收。本阶段的软件结果不替代这些设备与工况测试。
