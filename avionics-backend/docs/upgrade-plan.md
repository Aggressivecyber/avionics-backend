# 地面监测后端软件升级验收计划

本阶段以地面试验和总线监测为范围。开发分支为 `codex/ground-backend-v03`，基线为 `0f00e927424f73fe5deb07b7da41aab13527ecf1`；开发、构建和运行文件放在 E 盘，原工作区保留基线。

当前审计及复现位于 [架构审计](E:/avionics-audits/20261019-architecture-094835/architecture-audit.md)。

| 工作项 | 验收条件 | 状态 |
| --- | --- | --- |
| 配置与状态容量 | 声明的参数状态在采集前完成预算检查，超限配置不能在采集中途首次报错 | 已通过 4097 参数的拒绝与扩容运行验收 |
| 字段与规则索引 | 无关字段和规则不逐项扫描，既有输出语义保持一致，记录扩展微基准 | 字段、时钟与输入规则索引已通过，截止调度后续处理 |
| 核心接口依赖 | 参数接口独立于归档、队列及线程实现 | 已完成并通过构建 |
| 事件时间 | 明确配置允许迟到范围，有界重排；范围内跨来源排列结论一致，截止和空闲边界有测试 | 已通过 60 种来源交错、截止水位及异常时间验收；生命周期空闲状态随采集监督实施 |
| 记录与分析隔离 | 分析故障或积压不终止原始记录，持久化缺口和分析游标明确，原始存储失败仍显式失败 | 已通过异常、队列及收尾故障注入和完整离线重算 |
| 输入预算 | 总量和来源分别有条数、字节预算及拒绝原因 | 已通过条数、字节及来源状态容量验收 |
| 会话封存 | 新格式可验证记录数量、长度和内容；能区分未封存输入；旧 v1 文件仍可读 | 已通过 69 类破损、旧版样本及并发独占写入验收 |
| 异步故障 | 工作线程错误可通过公开状态取得原因并保存在会话结果 | 待实施 |
| 升级兼容 | 宿主与旧插件互操作、旧归档读取、配置和发布版本可追溯，失败替换可回滚 | 待实施 |
| 证据身份 | 配置解析字节与保存快照一致，配置内容和会话有稳定身份 | 已通过在线离线相同身份及 Python 独立摘要复核；回放跨会话身份随 ABI 升级实施 |
| 用户态故障隔离 | 通用采集进程崩溃或挂起时宿主及其他来源保持可用，停止与恢复结果可查询 | 待实施 |
| 交付验证 | 干净构建、全部回归、故障注入、兼容测试和可核验收据通过 | 待实施 |

实施顺序为容量与索引、事件时间、记录隔离、封存与追溯、插件兼容及采集进程边界，最后汇总交付验证。每个阶段先加入覆盖审计问题的验收，再提交对应实现。

真实总线识别算法、采集卡 SDK、设备参数 ICD 和绝对吞吐、延迟及连续运行目标，在规格确定后验收。本阶段的软件结果不替代这些设备与工况测试。
