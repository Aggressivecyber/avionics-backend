# AEROBUS v0.7.0 · 可分发桌面版

适用平台为 Windows x64。解压整个 Release 文件夹后双击 `AEROBUS.exe`，无需安装 Python、Qt、编译器或管理员权限。`AEROBUS-Analysis.exe` 是配套计算程序，和 `_internal/`、`bin/`、`config/`、`asset/` 一起保留。试验数据请选择 D/E 盘；默认使用 E 盘，E 盘不存在时使用 D 盘。发布目录与项目数据目录相互独立。

## 项目与采集

v0.7新增场景验证插件。配置正常运行、参数越限、响应超时后，手动开始采集；预设数据生成完成后自动封存并输出逐项验收结果。可点击结果查看原始报文，在历史记录中复核以往场景。详见[场景验证与自动验收](scenario-acceptance.md)。

在“项目设置”填写名称、根目录并保存字典。“新建项目”生成 `.aerobus.json` 项目文档，内部资源放在根目录 `projects/<项目ID>/`。一个项目可包含多次采集；“结束并封存”结束本次采集，之后“开始采集”恢复项目保存的来源配置并生成新记录。启用插件只准备来源，仍需手动开始。

v0.6.1修复准备阶段不能编辑字典与规则的问题。新建项目或启用插件后，尚未开始采集时可以点击输入框修改、保存。保存通过后会封存当前准备记录，保留插件来源设置；再点击“开始采集”使用新配置。采集已经开始时，页面明确提示先“结束并封存”再编辑，原记录的配置快照保留。

“打开项目”及“最近项目”恢复名称、字典、关系、来源设置、页面和分隔条布局。资源使用根目录相对路径，整体复制根目录后可重新打开。内置插件按发布包中的库名解析；外部插件的绝对路径会明确保存，复制项目时需要一并提供外部插件与它依赖的厂商 SDK。已有采集归档与配置快照保留。

同时编辑同一项目的多个程序实例不在本版验收范围。复制前先完成封存和完整分析保存；打开复制后的项目会为新采集生成独立记录。

## 完整关系与复算

自定义关系由独立进程读取完整 `parameters.jsonl` 计算，不依赖界面显示缓冲。关系定义保留稳定ID与SHA-256版本；修改后从本次采集的开头重算并保留各定义版本文件。最新定义用于整次记录，修改不表示只作用于修改时刻之后。

完整结果、输入记录位置、有效性、除零及对齐失败等状态写入关系JSONL和磁盘历史索引。界面仅保留有界的最近曲线。结束时等待计算读完所有参数、保存摘要和报告；计算进程错误单独记录为 `analysis-failure.json`，采集封存状态与分析状态分别判断。

离线分析优先使用原记录保存的关系快照，调用同一公式引擎。验收要求同一原始归档与配置的参数、事件、关系结果逐字节一致。缺口、无效质量和来源代次变化不会被拼接成连续有效结果。

## 历史、异常与报告

“历史与报告”选择采集记录、时基、最多4项参数或关系，并设置时间范围。点击曲线选择显示点，滚轮缩放；双击规则事件定位原始记录。比较记录时，以每次记录在所选时基的首个样本为0秒，曲线独立纵轴并标明单位，不推断两次试验的绝对同步。曲线预览保留显示桶中的极值和质量断点；所有点仍可导出。

原始报文窗口先由后端检查整份归档封存，再显示十六进制、会话身份及1553B命令/状态/数据字。1553B字角色使用已有后端解析器的结果。参数涉及的数据字根据配置快照高亮；坏帧仍显示捕获字和明确诊断。

“试验备注与报告”保存项目步骤、本次采集名称和备注，并导出 HTML 报告及完整参数、事件、关系 CSV。HTML 可在浏览器查看、打印或另存为 PDF。条件公式的 true/false 只表示表达式结果，试验是否合格需由明确判据决定。报告包含统计、曲线、异常及原始记录位置、配置和结果摘要。

## 构建与验收

源码、构建和发布输出均放在 D/E 盘。CMake 使用 Release 构建，并启用 `AVIONICS_TEST_QT_FRONTEND=ON`。执行 CTest；新增 `qt_workbench` 验证显示历史溢出时完整关系仍保存、在线离线摘要一致、项目复制重开、第二次采集、历史比较、报告与CSV。

打包环境安装 `frontend/requirements-release.txt`。使用：

```powershell
python scripts/package_release.py --build D:/avionics-builds/ground-backend-v03-final --output E:/avionics-releases/v060/AEROBUS --freeze-python E:/avionics-tools/aerobus-release-env/Scripts/python.exe
```

打包要求源码已提交、工作树干净且后端提交身份准确。构建缓存、日志和临时文件放在发布目录旁的 `*-freeze-build/`。包中提供源码ZIP、依赖许可、文件清单和SHA-256。

从最终包执行 `AEROBUS-Analysis.exe --release-check --output E:/aerobus-release-verification`，可以在没有外部 Python/Qt 的路径环境中运行原生Qt验收并生成截图及收据。详细结果以本次交付的验收记录为准。

本版1553B仍为软件合成监控输入。真实采集卡、厂商SDK、ICD、通道负载和长时间运行须在设备确定后验收，范围见 `product-acceptance.md`。本版不提供真实总线发送控制。
