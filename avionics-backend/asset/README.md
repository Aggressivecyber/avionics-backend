# AEROBUS 美术素材

本目录统一存放工作台使用的素材。`prompts.json` 记录30个独立生图素材的用途、提示词、尺寸、透明背景及SHA-256；使用内置 `image_gen` 生成。

[查看完整素材预览](catalog.png)

- `icons/`：24个功能图形，覆盖导航、插件、采集操作、参数关系、时间对齐与证据溯源。
- `background/`：浅色总线纹理工作台背景，保持文字和白色数据区域清晰。
- `illustrations/`：插件场景、监测等待、归档空状态、数据关联与回放流程。
- `aerobus.svg`、`chevron-down.svg`：原有品牌标记和原生控件箭头。
- `generated/`：本次生图原始输出与迭代版本，实际存储在E盘，不纳入Git和便携发布包。

图形与现有中文标签共同说明功能。背景只用于工作台外框，场景和流程图用于说明或等待状态；曲线、数值和质量状态始终来自实际数据处理结果。素材在Qt中按显示尺寸缩放，原始PNG保持不变。
